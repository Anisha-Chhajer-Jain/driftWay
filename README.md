# DriftWay Documentation

A simple, fast documentation site built with Next.js App Router and clean CSS.

## Getting Started

Run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001) in your browser.

## Features
- File-based documentation routing
- Clean sidebar navigation
- Dynamic guide and reference articles
- Custom 404 page
